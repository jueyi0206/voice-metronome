# 人聲音檔放這裡

檔名：`1.mp3` ～ `8.mp3`（wav / m4a / ogg 也可以，八個要同一種副檔名）。
放好之後開頁面會自動載入。

實際上只會用到 1~4 —— 一小節最多 4 拍，三連音只數到 3。

## 錄音注意

- **開頭的靜音不用剪** —— 程式會自動裁掉，念完整就好。
- 用同一支麥克風、同一個音量、同一種語氣錄。
- **每個字念短一點，整個字控制在 200ms 以內。** 120 BPM 的三連音一格
  只有 167ms，念太長尾巴會被收掉。開頭是 ㄙ 的字（三、四）特別要注意，
  摩擦音拖太久的話，整格播完都還沒進到母音。
- 單聲道、44.1kHz 就夠。
