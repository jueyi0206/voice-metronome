# 中文人聲節拍器

兩種數拍子的聲音，二選一：**敲木魚**（最後一拍聲音不一樣），或**中文人聲念「一二三四五六七八」**。

單頁、零相依、零安裝，開 `index.html` 就能用。

---

## 兩種聲音

**木魚** — 程式合成，不吃任何音檔。一小節最後一拍會換成另一個聲音：音高從 1200Hz 降到 760Hz、長度從 38ms 拉到 63ms、音量更重。低、長、重，聽起來像「收」，不用數也知道一小節到了。

重音要放第一拍也可以，或兩種都不要。

**中文數拍** — 念出數字。音檔放 `voice/1.mp3` ～ `voice/8.mp3`，開頁面自動載入，排在 Web Audio 時鐘上，跟木魚一樣準。**開頭的靜音會自動裁掉**，所以錄的時候不用對齊 —— 程式看波形就知道聲音從哪裡開始（門檻取峰值 2%，起音前留 3ms 免得削掉子音的氣音頭）。

缺檔的時候才會在「聲音」區塊下面講一行。

## 細分

每個選項的按鈕上畫的是對應的樂譜記號（inline SVG，不是 ♩♪ 那些字元 —— 字元在不同字型下大小和基線差太多）。

| 選項 | 記譜 | 一拍之內 | 120 BPM 實測 |
|---|---|---|---|
| 不分 | ♩ | 一下 | 500ms |
| 三連音 | 三個八分連桿 + 3 | 1:1:1 | 166.7 / 166.7 / 166.7ms |
| 長短拍 | 四分 + 八分，標 3 | 2:1 前長後短 | 333.3 / 166.7ms |
| 附點 | 附點八分 + 十六分 | 3:1 前長後短 | 375 / 125ms |
| 反附點 | 十六分 + 附點八分 | 1:3 前短後長 | 125 / 375ms |

節奏型不是寫死「切成幾等份」，而是一組**一拍之內的位置**（`[0]`、`[0, 1/3, 2/3]`、`[0, 2/3]`、`[0, 3/4]`、`[0, 1/4]`），所以不等分的長短拍、附點跟等分的三連音走同一套排程。要加別的型只是多一行。

- **木魚模式**：中間那幾下是 2300Hz 的輕點，音量 0.16，相對正拍 0.6、重音 1.0。
- **中文數拍模式**：改成**在一拍之內數** —— 三連音「一、二、三」，長短拍／附點／反附點「一、二」。不分的時候才數小節的拍。

人聲在細分時會被收短：音檔三、四百毫秒，但 120 BPM 的三連音一格只有 167ms，不收掉三個字會糊在一起。超過就在結尾淡出 30ms 收掉。

## 準度是怎麼來的

節拍器會飄，幾乎都是因為用 `setInterval` 排拍子 —— JavaScript 的計時器本來就不保證準時。

這裡用的是標準做法：`setTimeout` 只負責**每 25ms 醒來看一次**，真正的發聲時間是算好之後交給 Web Audio 的 `currentTime` 時鐘，由音訊執行緒播。排程一次看未來 150ms，所以就算主執行緒卡住，已經排進去的拍子照樣準時響。

實測 120 BPM 三連音，攔截實際排進時鐘的時間：每下間隔 166.7ms，最大偏差 0.033ms。

拍燈跟著 `requestAnimationFrame` 走，分頁切到背景時瀏覽器會降頻，燈會跳 —— **但聲音不受影響**，因為它早就排好了。欠了好幾拍的時候只畫最新那一拍，不補動畫。

## 把八個字對齊

`tools/align_voice.py` 把任意一組 1~8 的音檔整成長度、音量一致：

```
python tools/align_voice.py <來源資料夾> <輸出資料夾> [--target 毫秒]
```

1. 裁掉頭尾靜音
2. **變速**到同一個長度（atempo，不變調）—— 不是裁切，像「三」那種字裁下去會在母音中間被砍斷
3. 對齊音量到**最響 100ms 窗**的 RMS
4. 淡入淡出並補到剛好的長度

音量為什麼不用 ffmpeg 的 `loudnorm`：EBU R128 的量測區塊是 400ms，這些字只有 100~400ms，量出來是 `-inf`，整個失效。峰值對齊會讓短而密實的字過響，整段平均能量又會被長摩擦音拉低而過度增益。最響的 100ms 窗是短音的合理折衷。

`--max-stretch` 限制變速倍率（預設 1.6），超過就不強求等長 —— 變速拉太多會有金屬聲。

## 時間對齊是對母音，不是對檔頭

這點比長度和音量都重要。「七」的ㄑ送氣音長達 195ms、「四」的ㄙ 90ms，如果把檔頭對在拍點上，這些字的母音就會遲到 —— 數到七會明顯卡一下。

人唸拍子本來就是把母音對在拍上、子音自然提前，所以程式載入時會用零交越率找出每個字的母音起點（摩擦音與送氣音 6000Hz 以上，母音多半 1500Hz 以下），播放時提前那麼多秒觸發。

實測 100 BPM 數八拍，檔案起點各自錯開 0~200ms，母音落點間隔全部正好 600ms。

## 錄人聲的注意事項

- 開頭的靜音不用剪，程式會處理。
- 八個檔用同一支麥克風、同一個音量、同一種語氣錄。
- **每個字念短一點，整個字控制在 200ms 以內。** 120 BPM 的三連音一格只有 167ms，念太長後面會被收掉 —— 像「三」「四」這種開頭是 ㄙ 的字特別吃虧，摩擦音拖太久的話，整格播完都還沒進到母音。
- 單聲道、44.1kHz 就夠。
